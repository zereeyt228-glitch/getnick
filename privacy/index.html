Политика конфиденциальности

Актуально на 23 сентября 2026 года.

1. Основной сервис

GetNick предоставляет генераторы и информационные страницы. Для использования основных функций регистрация не требуется.

2. Данные в браузере

Локальное хранилище может использоваться для темы интерфейса и избранных никнеймов. Эти данные остаются на устройстве пользователя.

3. Генератор паролей

Пароли создаются кодом в браузере и не отправляются сайтом на сервер. Пользователь самостоятельно отвечает за безопасное хранение паролей.

4. Технические данные

Хостинг может автоматически обрабатывать стандартные технические данные запроса, необходимые для доставки страниц и безопасности.

5. Изменения

Политика может обновляться вместе с развитием проекта. Актуальная версия находится по адресу getnick.ru/privacy/.
