# GetNick.ru

GetNick.ru — быстрый статический генератор никнеймов для игр, стримов и социальных сетей.

## Что есть в текущей версии

- генератор ников с несколькими стилями;
- настройка длины, префикса, суффикса, цифр и оформления;
- локальное избранное через `localStorage`;
- отдельные страницы для Steam, Roblox, Minecraft, Valorant и Twitch;
- генератор паролей на `crypto.getRandomValues()`;
- светлая и тёмная темы;
- адаптивный интерфейс;
- offline fallback через Service Worker;
- чистые URL без `.html` в основной навигации.

## Чистые маршруты

- `/` — главная и генератор;
- `/generator/` — отдельная страница генератора;
- `/passwords/` — генератор паролей;
- `/steam/`;
- `/roblox/`;
- `/minecraft/`;
- `/valorant/`;
- `/twitch/`;
- `/about/`;
- `/privacy/`.

Старые адреса вида `steam-niki.html` сохранены как страницы-перенаправления, чтобы старые ссылки не ломались.

## Структура

- `index.html` — главная;
- `assets/styles.css` — общий дизайн;
- `assets/app.js` — генераторы, тема, избранное и интерактивность;
- папки маршрутов содержат собственные `index.html`;
- `sitemap.xml` и `robots.txt` — индексация;
- `sw.js` и `offline.html` — offline fallback.

## Развёртывание

Проект рассчитан на GitHub Pages с пользовательским доменом из `CNAME`: `getnick.ru`.

## Важное про проверку ников

GetNick не заявляет, что имя точно свободно без ответа API конкретной платформы. В интерфейсе есть быстрые ссылки для ручной проверки на сторонних сервисах.
