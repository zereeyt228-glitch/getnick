# getnick
⚡ GetNick.ru — Умный генератор оригинальных никнеймовGetNick.ru — это современное веб-приложение (PWA) для быстрой генерации редких, стильных и уникальных никнеймов для геймеров, стримеров и пользователей социальных сетей (Steam, Roblox, Geometry Dash, Minecraft, PUBG, YouTube, Twitch и др.).

✨ Основные возможности🎲
  Умная генерация по категориям: Все подряд, Игровые, Киберпанк, Фэнтези, Минимализм.
  Настройка длины слова (от 4 до 12 символов).
  Автоматическая замена букв на похожие цифры (например, o -> 0, i > 1).

🎨 Стилизация шрифтов и декор:
  Кастомные стили текста на базе Юникода (Gothic, Double-struck, Circles, Spaced).
  Добавление префиксов и клантегов (xX_, pro_, _offc, _gd и т.д.).
  Украшение спецсимволами (༺★༻, ꧁꧂, ⚡, 『』).
  
🔍 Проверка занятости никнейма:
  Автоматическая онлайн-проверка уникальности имени через поисковую сеть Google (с использованием AllOrigins Proxy).
  Быстрые ссылки для проверки ника на платформах: Google, YouTube, Twitch, Steam.
  
⭐ Избранное и История:
  Сохранение понравившихся вариантов в LocalStorage браузера в 1 клик.
  История последних сгенерированных никнеймов.
  
🌙 Темы и интерфейс:
  Поддержка Тёмной, Светлой и Системной тем оформления.
  Современный стеклянный дизайн (Glassmorphism) и адаптированность под мобильные устройства.
  Синтезированные звуковые эффекты нажатий без внешних аудиофайлов (Web Audio API).
  
📶 Полный оффлайн-режим (PWA):
  Встроенный Service Worker (sw.js) кэширует автономную страницу.
  Возможность локальной генерации ников и просмотра сохранённого «Избранного» даже при отсутствии сети.
  
🛠️ Технологический стек Frontend:
  Frontend:
    HTML5, CSS3 (CSS Variables, Flexbox, Grid, Glassmorphism, CSS Animations).
  JavaScript:
    Pure Vanilla JS (ES6+), Web Audio API, LocalStorage API, Fetch API.
  PWA:
    Service Worker (sw.js).
    
✏️ Библиотеки и Шрифты:
  FontAwesome 6, Google Fonts (Plus Jakarta Sans, JetBrains  Mono).
