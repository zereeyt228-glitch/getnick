# GetNick.ru

GetNick.ru — небольшой набор статических браузерных генераторов.

## Генераторы

- **Ники** — стили, точная итоговая длина, префикс, суффикс, цифры и оформление.
- **Пароли** — локальная генерация на `crypto.getRandomValues()`.
- **Названия** — идеи для проектов, каналов, команд, кланов и брендов.

## Основные маршруты

- `/` — главная;
- `/generator/` — генератор ников;
- `/passwords/` — генератор паролей;
- `/names/` — генератор названий;
- `/about/` — о проекте;
- `/privacy/` — конфиденциальность.

Старые страницы по отдельным игровым платформам больше не используются как самостоятельные разделы и перенаправляют на общий генератор ников.

## Структура

- `assets/styles.css` — общий дизайн;
- `assets/app.js` — генераторы, тема, избранное и интерактивность;
- `sw.js` и `offline.html` — offline fallback;
- `sitemap.xml` и `robots.txt` — индексация.

Проект разворачивается на GitHub Pages с доменом `getnick.ru`.
